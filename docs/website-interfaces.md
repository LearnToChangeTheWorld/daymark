# 本地运行与网站接口

当前交付方式是 Windows 本地运行：浏览器连接这台电脑上的事项服务，事项服务直接管理本机账号和采集器，数据写入本机目录。不提供线上网址，不要求服务器或域名，也不接受来自局域网的访问。手机当前不能远程使用。

本地模式默认监听 `127.0.0.1:4317`，支持显式使用 `::1`，不接受通配地址或电脑的局域网地址。页面与所有 API 都要求本机连接及回环 Host。使用原有访问码和会话登录，不重置既有数据或已保存账号。

## 平台网站接入继续保留

| 来源 | 当前状态 | 登录与采集位置 |
| --- | --- | --- |
| 微信、QQ | 保留现有扫码接入、登录状态恢复及群消息读取 | Windows 本机及对应客户端 |
| 学习通 | 保留账号密码登录、课程、作业与通知读取及人工验证窗口 | Windows 本机 |
| 雨课堂、中南大学教务 | 保留来源定义与后续适配位置，真实采集器尚未实现 | 后续仍优先在本机接入 |

连接第三方平台需要互联网。这里的“本地运行”描述软件和数据放在哪里，并不表示断网后还能取得平台新内容。

## 网站同步接口继续保留

以下地址均相对于事项服务。当前可在本机使用；保留其结构，是为了后续扩展网站时复用采集、去重和事项处理代码。

| 接口 | 用途 | 鉴权 |
| --- | --- | --- |
| `POST /api/pair` | 输入软件访问码，建立网页会话 | 访问码；返回 HttpOnly 会话 Cookie |
| `GET /api/state` | 读取事项、来源状态及运行模式 | 网页会话 |
| `POST /api/items` | 新建待办 | 网页会话 |
| `PATCH /api/items/:id`、`DELETE /api/items/:id` | 修改或删除事项 | 网页会话 |
| `POST /api/items/archive` | 按明确的记录 ID 列表批量归档或恢复，同一事务保存 | 网页会话 |
| `POST /api/collector/events` | 上传标准事件，保存后返回确认 | 独立采集端 Bearer 密钥 |
| `POST /api/collector/heartbeat` | 上报采集端和来源状态 | 独立采集端 Bearer 密钥 |
| `/api/accounts/*` | 平台登录、验证码、群识别与采集管理 | 网页会话，且只允许本机模式 |

`collector/worker.mjs` 继续支持本机耐久队列、失败重试及 HTTPS 上传；`collector.config.example.json` 默认仍指向本机，不会自动连接其他服务器。稳定的来源与事件 ID 用于去重，重复同步不会覆盖用户已修改或完成的事项。接口字段定义仍在 `shared/events.mjs`，无需为本地版另造一套事件格式。

## 未来网站方案，当前不启用

`STUDENT_INBOX_MODE=cloud` 显式启用的模式及 `Dockerfile`、`compose.yaml`、`Caddyfile.example`、`.env.example` 继续保留。普通 `npm start` 或 `node server.mjs` 默认不会启用此模式；本地模式使用旧的 `--lan` 参数或非回环 HOST 会直接报错。

预留的云端模式要求 HTTPS 网关，只处理事项和上传事件，不允许管理平台密码。未来使用时，Windows 电脑可通过 HTTPS 主动同步，不需要校园网的入站端口。但目前本机学习通与聊天账号模块还未完整迁移至独立采集端，不能仅修改服务器地址就宣称全部平台已经支持云同步。

代码测试覆盖本地访问限制及预留 API；Docker 构建、真实域名、HTTPS 部署、手机访问及后台推送尚未完成验证。等需要上线时，再完成这些工作，并更新 README 的运行范围说明。
